# PDF Studio

أدوات PDF بالعربية والألمانية والإنجليزية، تعمل داخل المتصفح دون رفع المستندات إلى خادم.

## الميزات

- محرر للكتابة والرسم وإضافة الصور واستبدال النص الموجود بصرياً.
- دمج الملفات بالترتيب، وتقسيمها حسب النطاقات أو إلى ملف لكل صفحة مع تحميل ZIP.
- حذف الصفحات واستخراجها وترتيبها وتدويرها مع معاينة مصغّرة.
- تحويل الصور إلى PDF، وتحويل صفحات PDF إلى PNG أو JPG وتحميلها معاً.
- الضغط، التوقيع المرئي، أرقام الصفحات، العلامة المائية، القص والحجب.
- تجهيز ملف واحد من PDFs وصور للمعاملات.

استبدال النص متاح للنص القابل للتحديد، وليس OCR. عند التصدير، تُحوّل الصفحة التي استُبدل نصها إلى صورة لمنع بقاء النص القديم تحت التعديل. صفحات الكتابة العادية تحافظ على محتواها الأصلي وتُضاف طبقة مرئية فوقها. التوقيع مرئي وليس توقيعاً رقمياً بشهادة.

الضغط المتوسط والقوي يحوّل الصفحات إلى صور مع الحفاظ على أبعاد الورق، ويفقد النص قابلية البحث والنسخ. الحجب يُصدّر المستند كصور بعد رسم مناطق الحجب. القص يغيّر المنطقة المرئية ولا يحذف المحتوى خارجها.

## التطوير

```sh
cd source
pnpm install --frozen-lockfile
pnpm dev
```

## التحقق والبناء

```sh
pnpm test
pnpm exec playwright install chromium
pnpm test:browser
pnpm build
```

أمر البناء يجهّز `source/dist/` ويحدّث نسخة Hostinger في جذر المستودع تلقائياً. لا يحذف مجلدات صور المستخدمين القديمة.

## البنية

- `source/src/main.js`: واجهات الأدوات والمحرر والتفاعل.
- `source/src/pdfOperations.js`: منطق الدمج والتقسيم واختيار الصفحات مع اختبارات مستقلة.
- `source/src/toolsData.ts`: سجل الأدوات وتصنيفاتها.
- `source/src/translations.json`: الترجمات الثلاث.
- `source/src/style.css` و`workspace.css`: أساس المحرر وواجهة مساحة العمل.
- `source/public/`: الموارد العامة وإعدادات الاستضافة.
- `source/tests/`: اختبارات منطق PDF وتدفقات المتصفح وتنزيل الملفات.
- `assets/` و`index.html`: نسخة النشر المبنية.

## النشر

راجع [دليل Hostinger](HOSTINGER_GIT_DEPLOY_AR.md). لا يحتاج محرر PDF إلى PHP أو قاعدة بيانات. ملفات PHP الصغيرة الخاصة بـ robots وsitemap تولّد عناوين النطاق الحالي على Hostinger.

أزيل إنشاء QR وBarcode ورفع الصور إلى روابط عامة. تُرجع مسارات الخدمة القديمة استجابة 410 في Apache، وتحوّل صفحاتها القديمة إلى الصفحة الرئيسية. تبقى أي ملفات مستخدمين قديمة على الاستضافة دون حذف.
